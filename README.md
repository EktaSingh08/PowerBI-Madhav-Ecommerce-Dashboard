# Power BI Madhav E-commerce Sales Dashboard

## Situation
Madhav is an e-commerce business that required a consolidated view of its sales performance to better understand revenue, profit, customer behavior, and product trends.  
The available data existed in raw transactional format, making it difficult for stakeholders to quickly derive insights for decision-making.

## Task
The objective was to design an interactive Power BI dashboard that:
- Presents key business KPIs at a glance
- Analyzes sales and profit performance across categories and regions
- Identifies customer and payment behavior
- Highlights monthly profit trends to support strategic planning

## Action
To achieve this, I performed the following steps:
- Cleaned and preprocessed raw sales data using Microsoft Excel
- Built a data model in Power BI and created calculated measures using DAX
- Designed an interactive dashboard with slicers for category, state, and payment mode
- Visualized key metrics including total sales, profit, AOV, quantity sold, and monthly profit trends
- Structured the dashboard layout to ensure clarity and business readability

## Results
The dashboard enabled clear and actionable insights, including:
- Maharashtra emerged as the highest revenue-generating state
- Clothing dominated in quantity sold, while Furniture and Electronics contributed significantly to overall revenue
- Cash on Delivery was identified as the most preferred payment method
- Monthly profit analysis revealed peak performance during specific months, indicating seasonal sales patterns
- High-value customers were identified, presenting opportunities for targeted engagement

## Tools Used
- Power BI (Data Modeling, DAX, Interactive Visuals)
- Microsoft Excel (Data Cleaning & Preprocessing)

## Outcome
This project demonstrates the ability to independently handle an end-to-end business analytics use case — from raw data to insight-driven visualization — using Power BI for real-world e-commerce decision support.
